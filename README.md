# AI notetakers: what each is called, how it gets into a meeting, and how to stop it

An open list of 90 AI meeting notetakers — the bots and built-in assistants that record and transcribe calls on Zoom, Google Meet, Microsoft Teams and Webex. For each one: the name it shows in a call, how it gets in (a participant, a calendar guest, a built-in feature), the chat command that removes it where one exists, and the steps to stop it joining.

Every line is taken from the maker's own help pages, and each entry links to them. A field the maker does not state is left out, not guessed.

The readable version, one page per notetaker, is at **[meetful.com/notetakers](https://meetful.com/notetakers)**.

## Files

- [`notetakers.json`](notetakers.json) — the full records: names, how it joins, how to stop it, what to do during a call, and the source pages.
- [`notetakers.csv`](notetakers.csv) — one row per notetaker, for spreadsheets.

Both are copies of [meetful.com/notetakers.json](https://meetful.com/notetakers.json) and [meetful.com/notetakers.csv](https://meetful.com/notetakers.csv), which are always the latest. Last updated 2026-11-11.
